-  # Project Layout

- `index.html` and the project-level `AGENTS.md`, `spec.md`, and `prompts.md` files belong at the top level.
- GitHub Pages uses the top-level `index.html`.
- Save supporting files only in the appropriate numbered folder:
- `00_planning/` - planning notes and sketches.
- `01_data/` - data files.
- `02_validation/` - hand calculations and test cases.
- `03_output/` - screenshots and exported results.
- Do not create project files in folders that do not match their purpose.
- Keep each folder's `README.md` up to date as a short description of that folder.

# Prompt Log

After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
